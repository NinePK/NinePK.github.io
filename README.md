https://ninepk.github.io

## Stack

- Next.js 16
- React 19
- TypeScript
- Static export
- GitHub Actions
- GitHub Pages

- **Restaurant** — POS & QR Ordering Management System
- **Internship Portal** — University Internship Management Platform
- **TESA Top Gun** — MQTT Embedded-System Backend, Silver Rank
- **Electric Cost** — ESP32 Electricity Cost Monitoring

## Local development

```bash
npm install
npm run dev
```

## Deployment

Every push to `main` triggers `.github/workflows/deploy.yml`, builds a static Next.js export, and deploys the `out` directory to GitHub Pages.
